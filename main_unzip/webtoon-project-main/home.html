ℹ️ 로컬 파일 직접 실행(CORS 제한) 구동 중:
브라우저 보안 정책으로 인해 file:/// 경로에서는 로컬 JSON 파일을 읽을 수 없으므로, 원격 깃허브 저장소의 JSON 데이터를 대신 실시간으로 연동하여 구동합니다.
(※ 대사 및 사운드 등의 무거운 미디어 리소스는 사용자님의 PC 로컬 폴더(자료/)에서 즉시 불러오므로 원활하게 감상하셔도 됩니다.)
만약 완전히 오프라인 상태이거나 로컬 디렉터리의 실시간 파일로 테스트하고 싶으시다면, 폴더 안의 server.ps1 서버를 기동하신 뒤 http://localhost:8000/home.html 경로로 접속해 주시기 바랍니다.
